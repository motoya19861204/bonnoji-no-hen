# 煩悩児の変

横スクロールのベルトアクション（ファイナルファイト風）。ブラウザで動きます。

## 遊び方
- `ゲームを起動.bat` をダブルクリック（ブラウザが開きます）
- 移動: 矢印キー / WASD　攻撃: Z（3連打で「ティッシュが」「ティッシュが」「やまも～り」）　ジャンプ: X（空中でZで飛び蹴り）
- スマホは画面上の仮想パッドで操作

## 調整
- `game/config.json` … 速度・体力・当たりの届く距離・コンボ猶予・敵の配置（waves）
- `game/assets/manifest.json` … スプライト・ボイスの登録（tools/build_sprites.py が生成）

## 素材
- `99_素材制作/` … 生成した原本と透過済み素材、ボイス、オープニング動画
- 画像: FAL gpt-image-2 / 動画・音声: FAL H3 Max Turbo
